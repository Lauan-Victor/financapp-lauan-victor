# financapp-lauan-victor
## Objetivo:
- FinancApp é um aplicativo de controle financeiro pessoal

## Funcionalidades:
- Cadastro e login
- Perfil (nome, turma, foto)
- Registrar lançamento (receita ou despesa)
- Ver extrato (lista de lançamentos + saldo)
- Marcar lançamentos com tags (ex.: "mercado", "transporte", "lazer")

## Tecnologias:
- HTML
- CSS
- JavaScript
- Github
- Supabase
